# PythonLab
Python Programming Lab repository containing 10 practical experiments covering data types, operators, control flow, loops, strings, lists, tuples, dictionaries, OOP, regular expressions, NumPy, Pandas, Matplotlib, data cleaning, exploration, and visualization. Designed for BCA students and beginners learning Python.
This repository contains the practical work and programming experiments completed as part of the Python Programming Lab. It is designed to demonstrate the implementation of fundamental Python concepts, programming techniques, object-oriented programming, regular expressions, and data analysis and visualization using popular Python libraries.

The repository covers 10 experiments, starting from basic Python programming concepts and progressing toward data handling and visualization. The programs are written in a simple and beginner-friendly manner to make them easy to understand, execute, and modify.

Experiments Covered

Experiment 1 – Data Types and Operators
Programs demonstrating different Python data types such as integers, floats, strings, lists, tuples, and Boolean values, along with various arithmetic, relational, logical, and assignment operators.

Experiment 2 – Control Flow and Looping
Implementation of conditional statements such as if, if-else, and if-elif-else, along with for and while loops.

Experiment 3 – String Operations
Programs demonstrating string creation, indexing, slicing, concatenation, repetition, and commonly used built-in string functions.

Experiment 4 – Lists
Implementation of lists and related operations such as adding, removing, updating, sorting, and accessing elements.

Experiment 5 – Tuples
Programs demonstrating tuple creation, indexing, slicing, and commonly used tuple functions.

Experiment 6 – Dictionaries
Implementation of dictionaries using key-value pairs, along with operations for adding, updating, deleting, and accessing data.

Experiment 7 – Object-Oriented Programming
Programs demonstrating important OOP concepts such as classes, objects, constructors, methods, inheritance, and encapsulation.

Experiment 8 – Regular Expressions
Implementation of Python's re module for pattern matching, searching, and extracting information from strings.

Experiment 9 – NumPy, Pandas, and Matplotlib
Programs demonstrating numerical operations and basic data analysis using NumPy and Pandas, along with data visualization using Matplotlib.

Experiment 10 – Data Cleaning, Exploration, and Visualization
Programs for loading datasets, cleaning and exploring data, and creating different types of visualizations to understand data effectively.

This repository serves as a learning resource and practical record for Python programming and data analysis.
