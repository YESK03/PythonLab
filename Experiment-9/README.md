# Experiment 9: NumPy, Pandas, and Data Visualization

## Aim

To understand the use of NumPy for array operations, Pandas for DataFrame creation and analysis, and Matplotlib for visualizing data through bar, line, pie, scatter, and histogram charts.

## Algorithm

### Part A: NumPy Array Operations

1. Import the NumPy library.
2. Create a one-dimensional NumPy array.
3. Modify selected elements of the array using their index positions.
4. Sort the array in ascending order.
5. Display the original array and the sorted array.
6. Find and display the minimum value, maximum value, elements in a selected range, and sum of the sorted array.
7. Create a structured NumPy array containing names, ages, and weights.

### Part B: Pandas DataFrame Operations

1. Import the Pandas library.
2. Create a dictionary containing student names, marks, phone numbers, USNs, and locations.
3. Convert the dictionary into a Pandas DataFrame.
4. Display the complete DataFrame.
5. Display the first and last rows using `head()` and `tail()`.
6. Display DataFrame information using `info()`.
7. Generate statistical summaries using `describe()`.
8. Sort the students by marks using `sort_values()` and display the result.

### Part C: Data Visualization with Matplotlib

1. Import Pandas and Matplotlib.
2. Create a DataFrame containing employee names, salaries, and scores.
3. Display the original employee data.
4. Create a bar chart of employee names against their salaries.
5. Create a line chart showing salaries across employees.
6. Create a pie chart representing the proportion of each employee's salary.
7. Create a scatter plot to study the relationship between employee scores and salaries.
8. Create a histogram to show the distribution of salaries.
9. Add suitable titles and axis labels, and display each chart using `plt.show()`.
